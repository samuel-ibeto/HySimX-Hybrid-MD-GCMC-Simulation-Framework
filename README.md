# HySimX-Hybrid-MD-GCMC-Simulation-Framework
This is a Hybrid Molecular Dynamics-Grand Canonical Monte Carlo Simulation Framework for eXtended Adsorption and Structural Relaxation in Host-Guest Systems. A Python-based automation framework that orchestrates iterative cycles of gas insertion and structural relaxation within a single, reproducible workflow using GROMACS and CASSANDRA softwares.
